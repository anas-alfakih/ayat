# آيات — موقع القرآن الكريم قراءةً واستماعًا

مشروع مفتوح المصدر ومجاني بالكامل: موقع ثابت (HTML/CSS/JS) عربي بالكامل وباتجاه RTL، يعرض آيات القرآن الكريم بالرسم العثماني مع تلاوة صوتية لكل آية، بدون خادم وبدون تسجيل وبدون إعلانات.

**الموقع المباشر:** https://anas-alfakih.github.io/ayat/

---

## دليل استخدام الموقع (للزائر)

### الصفحة الرئيسية

- تعرض **آية اليوم**: آية عشوائية من القرآن الكريم بنصها العثماني، مع اسم السورة ورقم الآية.
- زر **تشغيل** يبدأ تلاوة الآية المعروضة، وزر **آية أخرى** يجلب آية جديدة.
- زر **افتح المصحف الآن** ينقلك إلى صفحة القراءة الكاملة.

### صفحة المصحف

1. **اختر السورة** من القائمة المنسدلة (جميع السور الـ 114 مرتبة كما في المصحف).
2. **اختر القارئ** من قائمة تضم أكثر من 15 قارئًا (الافتراضي: مشاري العفاسي).
3. **التشغيل:**
   - اضغط زر التشغيل بجانب أي آية لتسمعها وحدها.
   - فعّل **التشغيل المتواصل** ليستمع الموقع السورة كاملة آية وراء آية تلقائيًا.
4. **شريط المشغل** أسفل الشاشة يعرض اسم السورة ورقم الآية واسم القارئ، مع شريط تقدم قابل للسحب وأزرار السابق/التالي والإيقاف.
5. الآية الجاري تشغيلها تظلّل تلقائيًا لتتبع القراءة مع الصوت.

الموقع يعمل مباشرة من المتصفح على الجوال والحاسوب، ولا يحتاج أي تطبيق أو حساب.

## بنية الكود (للمطور)

```
├── index.html    صفحة الهبوط (آية اليوم)
├── verses.html   صفحة المصحف (القراءة والاستماع)
├── style.css     التنسيقات المشتركة (عربي RTL بالكامل)
├── home.js       منطق صفحة الهبوط: جلب آية عشوائية وتشغيلها
├── app.js        منطق صفحة المصحف: السور والقراء والمشغل
└── README.md     هذا الملف
```

- **بدون أي اعتماديات بناء**: HTML + CSS + JavaScript خالص، لا يحتاج npm ولا خطوة بناء.
- **واجهة البيانات:** [AlQuran Cloud API v1](https://alquran.cloud/api) — مجانية، بدون مفتاح API، وتدعم CORS، وتُستدعى مباشرة من المتصفح.
  - النص: مصدر `quran-uthmani` (الرسم العثماني).
  - الصوت: إصدارات `versebyverse` من شبكة Islamic Network CDN.
  - القارئ الافتراضي معرّف في `app.js` بالثابت `DEFAULT_RECITER = 'ar.alafasy'`؛ غيّره لأي قارئ تدعمه الواجهة.
- **الخطوط:** Amiri Quran للنص القرآني وTajawal للواجهة (من Google Fonts).

## التشغيل محليًا

لا يحتاج المشروع أي تثبيت. افتح `index.html` في المتصفح مباشرة، أو شغّل خادمًا محليًا بسيطًا:

```bash
git clone https://github.com/anas-alfakih/ayat.git
cd ayat
python3 -m http.server 8000
```

ثم افتح http://localhost:8000

## انسخ المشروع وانشر نسختك الخاصة

المشروع عام ومفتوح للجميع، ويمكنك تعديله وإعادة نشره مجانًا:

1. **انسخ المستودع (Fork):** اضغط زر Fork أعلى صفحة المستودع على GitHub.
2. **عدّل الكود** كما تشاء، محليًا أو مباشرة من متصفحك عبر زر التعديل في GitHub.
3. **انشره عبر GitHub Pages:**
   - من إعدادات مستودعك: **Settings → Pages**.
   - في **Source** اختر **Deploy from a branch**، ثم اختر الفرع `main` والمجلد `/ (root)` واضغط **Save**.
   - بعد دقائق يصبح موقعك متاحًا على العنوان: `https://<اسم-مستخدمك>.github.io/ayat/`
4. يمكنك أيضًا نشره على أي استضافة ملفات ثابتة أخرى (Netlify أو Vercel أو غيرها) برفع الملفات كما هي.
